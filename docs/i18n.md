# Adding a language

Claude writes inloop's notes in any language you name. What a language file adds is inloop's own
text in that language: the line under an answer, the replies to `/inloop` commands, the cards'
headings and the review page's labels.

1. Copy `plugins/inloop/hooks/i18n/en.ts` to a file named after the language's ISO 639-1 code,
   for example `es.ts`, and translate every value. Keep the keys, and keep every `{placeholder}`
   exactly as it is.
2. Type the object as `Labels` (`export const es: Labels = { ... }`) so a missing key fails.
3. Counted labels have a form per plural category: `{ one: '{count} nota', other: '{count} notas' }`.
   inloop picks the form with the language's own plural rules, so a language with more categories
   (Polish, Arabic) can add them: `few`, `many`, `zero`, `two`.
4. Register the file in `plugins/inloop/hooks/i18n/index.ts` (`const LABELS = { en, tr, de, nl, es }`).
5. If the language is new to `hooks/config.ts`, add it to `LANGUAGES` with its English name, its
   own name and the spellings people type.
6. Run `claude plugin test plugins/inloop`. A test checks that every language has every key, the
   same placeholders and both plural forms, and that no label contains an em-dash.

Write the labels the way the language is used in software: short, plain, and in the same tone
as the other labels in that language.
