# inloop

Stay in the loop with the code your agent writes.

inloop is a Claude Code plugin. Before each change, Claude writes a short, structured note: what the
change does, why, the parameters that matter, and why each new class or function exists. You read
the notes live while Claude works and later as a review page, in the language you choose.

Status: in development. See [docs/plan.md](docs/plan.md).
